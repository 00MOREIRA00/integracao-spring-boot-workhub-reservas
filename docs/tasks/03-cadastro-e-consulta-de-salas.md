# Task 03 - Cadastro e Consulta de Salas

## Objetivo

Implementar a parte da API responsável por criar e listar salas.

## Escopo

- Criar endpoint para cadastro de sala.
- Criar endpoint para listagem de salas.
- Permitir filtro por status ativo/inativo.
- Validar nome e capacidade.

## Entregáveis

- Contratos HTTP para criação e listagem.
- Persistência de salas.
- Garantia de unicidade do nome.

## Critérios de conclusão

- Uma sala pode ser criada com sucesso.
- Tentativa de duplicar nome é rejeitada.
- A listagem pode filtrar por status.
