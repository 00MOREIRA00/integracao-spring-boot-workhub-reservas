# Task 09 - Docker e Empacotamento

## Objetivo

Preparar a aplicação para execução consistente em container.

## Escopo

- Criar `Dockerfile`.
- Usar imagem final sem ferramentas de build desnecessárias.
- Executar com usuário não privilegiado.

## Entregáveis

- Build de imagem funcional.
- Container sobe com a aplicação.
- Configuração compatível com produção.

## Critérios de conclusão

- A imagem pode ser construída localmente.
- O container expõe a aplicação corretamente.
- O processo não roda como `root`.
